FMTRX integration repair R07 — Player account ownership
2026-10-22

Local branches: fungoweb/main; mobile/TomsScreeens. No new branches/worktrees.

Root cause and correction
The legacy coach password endpoint let a coach supply a player's credential.
R06 restricted this to head coaches initializing passwordless players. R07 now
retires that capability entirely: unclaimed players use the existing invitation
and claim setup; existing accounts use recipient-controlled Password Recovery.
The compatibility route remains authenticated and checks coach role plus current
shared-team membership. It returns 403 and next_action for authorized coaches,
404 for unrelated/former/deleted targets, and never changes hashes or tokens.
Legacy coach status 0/1 does not change these rules.

Profile editing also allowed coaches to replace claimed account recovery email
and phone. Those fields are now owner-only for claimed accounts. A user row lock
serializes the check with claiming. Sports/profile editing and unclaimed contact
editing remain available through existing permissions and entitlements. Self-edit
remains available. No changes to age restrictions, invitation delivery switches,
claim tokens, IDs, history, subscriptions or team relationships.

Native roster editor removes coach password inputs/submission and explains the
invitation/recovery paths. Claimed contacts are read-only for coaches. Web roster
editor also presents claimed contacts as read-only and displays backend errors.
The server remains authoritative, including for older clients.
