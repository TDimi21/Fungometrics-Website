==================

Scope: supplied production Composer log; local application, routes, tests, config and bootstrap.
87 production warnings, 82 distinct class names. All 87 warned paths are absent locally.
81 of 82 names resolve locally from their canonical paths. All 735 local application declarations match PSR-4; no duplicate application declarations found.
Production file contents and direct/manual includes have NOT been inspected remotely. Matching class names do not prove identical implementations.

Findings and safest corrections
------------------------------
Keep existing App namespaces, canonical files, imports and route URLs. Do not rename the legacy classes to match their wrong folders: that can create competing implementations.
The four statistics services each occur in two warned server locations. GetTeamById also occurs in two warned locations. These share declared class names with canonical local implementations.
GetTeamsPlayers has a canonical local file but no references found; the current teams route uses GetTeamsPlayersV2 (see routes/api.php). Keep the older class until external/manual use is ruled out.
FilterTrainings_player has neither a canonical local file nor local references. Treat it as a server-only legacy candidate, not as safe to delete. The current filter route uses FilterTrainings.

Before any server cleanup: inventory git-tracked/untracked files, compare every warned file with its canonical counterpart, search server routes/config/scripts for direct includes and string-based references, and confirm reflection resolves each active class to the canonical file.
Back up and quarantine only verified redundant files outside all autoload roots in a reviewed deployment. Preserve or port any server-only behavior before removal. Do not use blanket rm or git clean.
No application file was deleted, moved or renamed during this audit. No production changes were made.

Local correction: rename the two LiveAB test class declarations to match their existing filenames; no references to the old names were found outside their declarations.
Regression contract freezes affected route methods/URIs/actions and verifies canonical class loading. Separate service tests exercise statistics with empty and nonempty data.
