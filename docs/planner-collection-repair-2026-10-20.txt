FMTRX R02 — Coach planner collection and deletion integration
Implemented locally, 2026-10-20. Web/backend main; mobile TomsScreeens.

Mobile advanced planner now requests GET /api/coach/daily-plans?team_id=...
on entry, focus and pull-to-refresh. Only a validated network collection can
replace confirmed cache rows. Pending edits and local drafts remain; other
teams are unaffected. Failed refresh shows an explicit device-copy message.
Account changes and superseded screen loads do not apply late responses.
The broader owner-scoped coach cache repair remains R04.

Delete calls DELETE /api/coach/daily-plans/{id}, with offline queueing disabled.
The device card is removed only after a confirmed success. Offline, denied,
missing and malformed responses retain it and explain refresh/retry. Drafts
with no version, pending submission or server marker may be discarded locally.
Cloning a server plan clears its version/sync metadata for the new draft.

Backend retains existing coach membership and entitlement middleware. Missing
or inaccessible plans now return 404 instead of a misleading success. Authorized
soft deletion and assignment removal run in one transaction; historical progress
is preserved. No schema or authentication changes.
